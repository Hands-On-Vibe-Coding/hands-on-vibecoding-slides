# 1️⃣ 왜 바이브 코딩인가?

- 단순한 자연어 코드 생성이 아니다  
- **서비스 기획 → 개발 → 운영** 전 과정에 AI를 통합  
- 목표: **적은 노력으로 높은 수준의 생산성과 품질 달성**

---

# 배경: 개발 패러다임의 변화

| 시대 | 주요 특징 | 대표 키워드 |
|------|------------|--------------|
| 2010s | DevOps | IaC, CI/CD |
| 2020s 초 | MLOps | Data-driven |
| **2025년~** | **Vibe Coding** | **AI-native Engineering** |

---

# 바이브 코딩의 정의

> “AI와 협력하여 소프트웨어 엔지니어링 전 과정을 가드레일 안에서 자동화·지능화하는 방식”

- Prompts = 새로운 코드 인터페이스  
- Agents = 동료 엔지니어  
- CI/CD, IaC, 보안, 테스트까지 포함

---

# 용어의 기원

- 2025년 2월, **Andrej Karpathy**가 제안  
- “Humans write vibes, AI writes code”  
- 불과 1년 만에 메인스트림으로 자리 잡음  
- 이유: **생산성과 품질의 압도적 격차**

---

# 생산성 격차의 예

- 1인 개발자도 엔터프라이즈급 아키텍처를 생성  
- 1주일 프로젝트 → 하루 만에 MVP 완성  
- 코드뿐 아니라 문서, 테스트, 배포 자동화까지 포함  
- **작은 스타트업도 빅테크 수준의 엔지니어링 가능**

---

# 실제 도입 사례 (Perplexity 조사 기반)

- **Perplexity AI**: 내부 도구 자동화에 바이브 코딩 활용  
- **Notion AI 팀**: 개발 문서 → 코드 → 테스트까지 자동 생성  
- **AWSKRUG 커뮤니티**: 서버리스 IaC 템플릿 자동화 실험  
- **Roboco / Hands-On Vibe Coding**: 교육 및 컨설팅 사례 다수

# 2️⃣ 바이브 코딩과 플랫폼 엔지니어링

---

# 플랫폼 엔지니어링이란?

> 개발자들이 스스로 서비스를 설계·배포·운영할 수 있도록  
> “내부 개발자 플랫폼(IDP)”을 구축하는 엔지니어링

- DevOps의 확장 개념  
- 셀프서비스 + 자동화 + 표준화  
- 대표 도구: AWS Control Tower, Service Catalog, Backstage 등

---

# 플랫폼 엔지니어링의 도전과제

- 각 팀마다 다른 언어/스택  
- 인프라 복잡도 증가  
- 거버넌스·보안 요구 강화  
- 운영 자동화 부담  
➡️ **AI 협업이 절실**

---

# 바이브 코딩과 플랫폼 엔지니어링의 만남

| 전통적 방식 | 바이브 코딩 기반 |
|--------------|----------------|
| 스크립트, 매뉴얼 작업 | 자연어로 IaC·파이프라인 생성 |
| 수동 승인 | HITL(인간-루프) 자동 승인 |
| 산발적 문서화 | 코드와 동기화된 문서 자동 생성 |
| 개별 스크립트 | 멀티 에이전트 자동 협업 |

---

# AWS Bedrock과 Claude 모델

- Claude 3.x 계열은 **소프트웨어 개발과 플랫폼 엔지니어링에 최적화**
- IaC, Terraform, Pulumi 코드 자동 작성
- 테스트케이스, CI/CD 워크플로 자동 생성
- 보안 설정과 모니터링 정책 추천

---

# 3️⃣ 바이브 코딩을 활용한 사례

---

# (1) 개발 자동화

- AWS CDK 또는 Terraform 코드를 프롬프트로 생성  
- 예:  
  “VPC와 Lambda, API Gateway를 연결한 서버리스 API 만들어줘”  
- Claude가 IaC, 테스트, 배포 파이프라인까지 자동 생성  
- CloudFormation 수준의 신뢰도 확보

---

# (2) 운영 자동화

- 로그 분석 → 이상 탐지 룰 자동 생성  
- AWS CloudWatch 경보 설정을 AI가 제안  
- 운영 문서와 Runbook을 자동 생성  
- AWS ChatOps와 통합되어 “AI SRE” 가능

---

# (3) 보안 자동화

- AWS Config 규칙 자동 생성  
- GuardDuty / Inspector 결과 분석  
- 취약점 수정 패치 스크립트 생성  
- K-ISMS / ISO27001 점검표와 연계 가능
